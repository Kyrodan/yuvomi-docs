# Notes

## What this module is for

Notes & Contacts combines two kinds of household reference data that are often needed quickly: short written notes and shared contact details. The result is a lightweight knowledge area for phone numbers, instructions, reminders and practical information that should not disappear in personal apps.

## What people usually do here

- Create colored Markdown notes for reminders, checklists, recipes or reference information.
- Pin important notes so they stay easy to find.
- Search the contact directory for phone numbers, emails and addresses.
- Import or export contacts as vCard data when moving to or from another system.

## How it connects to other modules

- [Family](./family) uses the same household people model and can overlap with shared contact information.
- [Birthdays](./birthdays) can selectively import from synced contacts.
- CardDAV sync helps keep Yuvomi aligned with other contact-aware tools the household already uses.

## Good to know

- Notes open in a rendered reader view first, with editing as a second step, which is helpful on mobile when you only want to read.
- Notes support full-text search, pinning and author-based filtering.
- Contacts expose each stored number, email and address as its own tap target instead of collapsing everything into a single summary field.
- This module is strongest as a shared household reference space, not as a private personal notebook.
