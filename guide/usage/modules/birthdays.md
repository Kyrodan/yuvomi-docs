# Birthdays

## What this module is for

Birthdays keeps recurring personal dates visible without asking the household to rebuild them manually every year. It is a focused module for remembering people, ages and reminders, while still fitting into the wider shared calendar flow.

## What people usually do here

- Add birthdays for family, friends and other important contacts.
- Review upcoming birthdays and current ages.
- Set reminders ahead of time for gifts, calls or event planning.
- Import birthdays selectively from contact data instead of entering everything by hand.

## How it connects to other modules

- [Calendar](./calendar) can receive automatic birthday events.
- [Contacts](./contacts) can supply contact data that includes birthdays.
- [Family](./family) helps keep core household member data aligned.

## Good to know

- This module is intentionally narrower than Calendar, so it stays good at one recurring job instead of becoming a second event editor.
- Automatic event creation reduces yearly maintenance effort.
- Selective import matters because not every synced contact should necessarily create a visible birthday inside the household calendar.
