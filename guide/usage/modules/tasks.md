# Tasks

## What this module is for

Tasks is Yuvomi's shared work board for chores, follow-ups and responsibilities. It is designed for household work that needs an owner, a due date, or a repeating rhythm. Unlike a simple checklist, a task can carry priorities, subtasks, categories, tags, linked documents and visibility rules.

## What people usually do here

- Create one-off tasks for school forms, repairs, errands or appointments that need follow-up.
- Use recurring schedules for routines such as trash, laundry, medication checks or weekly prep.
- Assign work to one or more family members and move it through the board as the status changes.
- Open a task in the read view when you only need details, then edit or complete it from there.

## How it connects to other modules

- [Rewards](./rewards) can award points when a finished task should count toward a family incentive system.
- [Documents](./documents) can be linked when a file belongs to the work item.
- [Reminders](./reminders) and the dashboard surface due tasks in the daily flow.
- Optional CalDAV sync can mirror tasks to reminder lists such as Apple Reminders, Radicale or Nextcloud.

## Good to know

- Visibility can be private, limited to assignees, or visible to everyone in the household.
- Task notes are useful for instructions and context; current releases render Markdown in the read view.
- Recurring tasks can repeat from the completion date, which is useful for routines that start when the previous run is actually done.
