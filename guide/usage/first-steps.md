# First Steps

Use this page after your first login to make Yuvomi comfortable for everyday use.

## Check your profile

Open **Settings** or your profile area and confirm:

- display name
- avatar or profile photo
- language
- notification preferences

## Understand the dashboard

The dashboard is your daily landing page. It usually highlights:

- tasks due soon
- calendar events
- shopping or meal-related items
- reminders or activity relevant to you

## Learn the navigation once

Most users do not need to memorize every module. Instead, learn this pattern:

1. Use the side or bottom navigation to open a module.
2. Use the module list or board to find your item.
3. Open the item detail view when more context is needed.
4. Save your change and return.

## Decide what matters to you

You may not need every module. A typical setup looks like this:

| User type | Usually used most |
| --- | --- |
| Parent or organizer | Tasks, Calendar, Shopping, Budget |
| Family member | Tasks, Calendar, Meals |
| Occasional user | Shopping, Calendar, Documents |

## Enable reminders carefully

Notifications are useful, but only if they stay relevant.

Start with:

- task reminders you truly act on
- calendar reminders for shared events
- shopping reminders only if your household uses them actively
