# Introduction

Welcome to the Yuvomi user guide.

This handbook is written for **end users**: people who open Yuvomi every day to manage tasks, appointments, shopping lists, meals, budgets, or documents. It does **not** focus on server setup or container deployment.

## What this guide helps you do

- understand where to start after receiving access
- install Yuvomi on your phone or desktop
- learn the most important navigation patterns
- use the main modules with confidence
- solve common issues before contacting support

:::tip Start here
If this is your first visit, continue with [Quickstart](pathname:///docs/quickstart).
:::

## Who this guide is for

This structure assumes three common reader types:

- **Invited family members** who need to sign in and get productive quickly
- **Household organizers** who coordinate shared routines inside the app
- **Occasional users** who mostly open Yuvomi for one or two modules

## How the handbook is organized

### Introduction

Explains the product, the audience, and the best entry point.

### Quickstart

Gets a new user into the app with minimal friction, including device installation.

### Usage

Shows the dashboard, first actions, and the modules people use most often.

### Help & Support

Provides short answers, troubleshooting steps, and a clear escalation path.

## Conventions used in the docs

- UI labels are written in **bold**
- menu paths use the format **Settings -> Notifications**
- commands are only included when an end user may actually need them
- deployment or server tasks should later move into a separate admin handbook

## Suggested next step

Move to [Quickstart](pathname:///docs/quickstart) to open Yuvomi for the first time and install it on your device.
