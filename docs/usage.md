# Usage

This section explains how people actually work in Yuvomi once the initial setup is done.

## Daily rhythm

For most households, the pattern is simple:

1. Open the **Dashboard** to see today's overview.
2. Move into the module you need.
3. Update or complete your item.
4. Return to the dashboard or switch to the next module.

## Core ideas

Yuvomi stays easier to learn when readers understand these ideas early:

- modules are independent, but share one navigation pattern
- some items are personal, others are visible to the household
- notifications support the workflow, but the dashboard remains the main entry point
