# Rewards

## What this module is for

Rewards turns household work into a structured incentive system. It is especially useful for families that want chores, routines or goals to lead to something visible and trackable instead of relying on memory or ad-hoc promises.

## What people usually do here

- Let completed tasks credit points to the assigned family member.
- Maintain a reward catalog that members can browse and redeem from.
- Approve or reject redemption requests when parental review matters.
- Review the ledger when someone wants to understand where a balance came from.

## How it connects to other modules

- [Tasks](./tasks) is the main source of points.
- [Family](./family) provides the member identities and roles that make approval and balances meaningful.

## Good to know

- A household-wide default point value can prefill new tasks.
- When that default changes, unfinished tasks can be updated to match the new rule.
- The ledger is explicit on purpose: it gives the module a clear audit trail instead of leaving balances unexplained.
- Rewards can stay opt-in per member, which helps when not every person in the household should use the same incentive system.
