# Documents

## What this module is for

Documents is the household filing area for forms, receipts, manuals and reference files. It is meant to keep important family paperwork accessible inside the same system that already holds tasks, budget entries and inventory items.

## What people usually do here

- Upload single files or batches of files.
- Organize them with folders, tags and visibility settings.
- Preview documents before downloading them again.
- Reuse the same file from other modules instead of storing duplicates everywhere.

## How it connects to other modules

- [Tasks](./tasks) can link documents when a file belongs to the work item.
- [Budget](./budget) can attach receipts to transactions and shared costs.
- [Inventory](./inventory) can link manuals, receipts and warranty-related files.

## Good to know

- External storage can be local, WebDAV or Google Drive, depending on how the household wants to store binaries.
- Paperless-ngx and Papra linking exists for households that already run a separate document management system.
- Visibility inside Yuvomi controls access through Yuvomi itself, but it does not override permissions in an external storage target.
- If documents are stored outside the database, those binaries need their own backup strategy in addition to Yuvomi's database backups.
