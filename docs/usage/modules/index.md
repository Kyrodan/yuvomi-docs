# Modules

Yuvomi is modular by design. Each module solves a clear household problem without forcing every member to use every feature. This section turns the current module list into individual handbook pages so readers can understand not only what a module is called, but how it actually fits into daily family use.

The list below follows the current homepage and repository documentation for the active module set.

## Module pages

## How to read these pages

Each module page focuses on four practical questions:

1. What problem the module solves
2. What people usually do there
3. How it connects to other Yuvomi modules
4. What an end user or admin should keep in mind before relying on it
