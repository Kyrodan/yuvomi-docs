# Quickstart

This section helps a new user get from invitation link to daily use with as little friction as possible.

## Before you begin

Make sure you already have:

- the URL to your household's Yuvomi instance
- an invitation link or valid login credentials
- a browser on desktop or mobile

## First-time flow

1. Open the URL shared by your household admin.
2. Sign in or accept your invitation.
3. Confirm your display name and profile details.
4. Check the dashboard to see today's items.
5. Install Yuvomi to your device if you plan to use it regularly.

:::note
If you are looking for Docker, Podman, NAS, or reverse proxy instructions, that belongs in an administrator guide, not this end-user handbook.
:::

## What success looks like

You are ready when you can:

- open the dashboard without asking for the link again
- switch into the modules you use most
- receive notifications on the device you care about
- find help without leaving the handbook
